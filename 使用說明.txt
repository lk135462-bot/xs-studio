  XS 工坊 使用說明
  用講話的方式，把你的交易想法變成 XQ 可以執行的腳本
════════════════════════════════════════════════════════════

這份說明假設你完全沒碰過這類工具。照著做就好，不需要任何程式基礎。
全部弄好大概要 10 分鐘，之後每次打開只要 3 秒。


────────────────────────────────────────────────────────────
  你需要準備的東西
────────────────────────────────────────────────────────────

  1. 一台 Windows 電腦
  2. 網路連線
  3. 一個「AI 的使用權」——三選一，等一下第 5 步會帶你設定：

     A. 你已經有訂閱 Claude（每月付費那種）→ 最省，不用再花錢
     B. 沒有訂閱 → 申請一把「API 金鑰」，用多少付多少
     C. 電腦有好一點的顯示卡 → 用自己電腦上的免費 AI

  不需要先安裝 Python，也不需要安裝任何其他程式。


────────────────────────────────────────────────────────────
  第一部分：把程式放進電腦（只做一次）
────────────────────────────────────────────────────────────

【第 1 步】下載壓縮檔

  點開別人給你的下載連結，把「XS 工坊-免安裝版.zip」存下來。
  檔案大約 125 MB，用一般家用網路大概 1～3 分鐘。

  下載完通常會放在「下載」資料夾裡。
  找不到的話：按鍵盤上的 Windows 鍵 + E 打開檔案總管，
  左邊那排點「下載」，剛下載的檔案會在最上面。


【第 2 步】解壓縮 ← 這一步最重要，跳過會失敗

  壓縮檔就像一個被壓扁的行李箱，要先「打開攤平」才能用。

  做法：
    1. 在「XS 工坊-免安裝版.zip」上面按【滑鼠右鍵】
    2. 選【解壓縮全部】
    3. 跳出來的視窗直接按【解壓縮】就好，不用改任何設定
    4. 等它跑完（大約 1～2 分鐘，檔案有點大）

  跑完會自動打開一個新資料夾，裡面有很多檔案。這樣就對了。

  ⚠ 常見錯誤：直接在壓縮檔裡面點程式
     Windows 允許你「偷看」壓縮檔裡面，看起來跟真的資料夾一樣，
     但在那裡點程式一定會失敗。
     判斷方法：視窗上方的路徑如果還看得到「.zip」，就是還沒解壓縮。


【第 3 步】打開程式

  在解壓縮後的資料夾裡，找到【XS 工坊.exe】，用滑鼠左鍵連點兩下。

  接下來會發生兩件事：
    1. 跳出一個黑底白字的視窗，寫著「XS 工坊 XS Studio」
       → 這是程式的引擎，不用理它，但【不要關掉】。關掉程式就停了。
    2. 幾秒後瀏覽器自動打開，出現深藍色的操作畫面

  看到深藍色畫面，就代表程式活著了。

  ⚠ 如果 Windows 跳出藍色的「已保護您的電腦」視窗
     點【其他資訊】→ 再點【仍要執行】。
     這是 Windows 對「還不認識的程式」的例行提醒，不是病毒警告。

  ⚠ 如果什麼都沒發生
     資料夾裡還有一支【備援啟動（若主程式打不開再用）.bat】，改點它試試。
     兩個都不行的話，看最後面的「遇到問題」那一段。


────────────────────────────────────────────────────────────
  第二部分：接上 AI（只做一次）
────────────────────────────────────────────────────────────

【第 4 步】看畫面上跳出來的「歡迎使用 XS 工坊」

  這個視窗會問你要用哪一種 AI。它已經先幫你檢查過電腦裡有什麼，
  所以先看第一個選項底下那行小字寫什麼。


【第 5 步】依照你的情況選一條

  ▍情況 A：小字寫「✓ 已登入 你的信箱（訂閱名稱）」

     恭喜，你什麼都不用做。
     直接按右下角【儲存並開始】，跳到第 6 步。

  ▍情況 B：小字寫「⚠ 已就緒，但還沒登入」

     1. 按【登入 Claude 帳號】
     2. 會跳出一個黑色視窗，照著上面的指示做
        （通常是按 Enter，然後瀏覽器會開一個登入頁面，登入後貼一段代碼回去）
     3. 弄完回到 XS 工坊的畫面，按【重新偵測】
     4. 看到「✓ 已登入」就按【儲存並開始】

  ▍情況 C：小字寫「⚠ 缺少必要元件」或「未偵測到」

     你有兩條路：
     ・照畫面上的連結去安裝它說缺少的東西，裝完按【重新偵測】
     ・或是改用第二個選項【Anthropic API Key】——那條完全不需要裝東西：
         1. 用瀏覽器開 console.anthropic.com，註冊帳號
         2. 儲值（最低金額就夠寫很多腳本了）
         3. 在網站上建立一把 API Key，複製它（一長串 sk-ant- 開頭的字）
         4. 回到 XS 工坊，點【Anthropic API Key】那一格，把金鑰貼進去

  選好之後，建議先按一下【測試連線】。
  等幾秒，看到綠色的「連線成功，AI 回覆：可用」就沒問題了。

  你的金鑰只會存在你自己這台電腦裡，不會傳給任何人。


【第 6 步】按【儲存並開始】

  視窗關掉，你會看到深藍色的主畫面。左下角那兩顆小圓點是綠色的，
  代表 AI 連線正常、XS 知識庫也載好了。

  設定只做這一次，以後打開就直接可以用。


────────────────────────────────────────────────────────────
  第三部分：寫你的第一支腳本
────────────────────────────────────────────────────────────

【第 7 步】點左邊的範例，或直接打字

  不知道怎麼開口，就點左邊「起手式」裡任何一句，它會自動填進下面的輸入框。

  想自己講也可以，用你平常跟人講策略的方式就行，例如：
    「月營收年增率連續三個月成長，而且股價站上季線的股票，幫我做成選股」
    「股價爆量突破前 20 日高點的時候通知我」
    「均線多頭排列進場，跌破 10 日線或虧 3% 出場」

  講得越具體越好：什麼商品、什麼條件進場、什麼條件出場、要不要停損。


【第 8 步】按【送出】，等它寫

  大約 30 秒。你會看到字一個一個跑出來，那是正常的。

  寫完之後你會看到：
    ・一段灰底的程式碼 ← 這就是你的腳本
    ・下面有說明，解釋為什麼這樣寫
    ・最後有「怎麼放進 XQ」的步驟

  上方那行「參考了知識庫 N 筆資料」可以點開，
  看它是根據哪些 XQ 官方資料寫的。


────────────────────────────────────────────────────────────
  第四部分：把腳本放進 XQ
────────────────────────────────────────────────────────────

【第 9 步】複製腳本

  在灰底程式碼的【右上角】，有兩顆按鈕：

    【複製】     → 整段複製起來，等一下直接貼上（推薦）
    【存成 .xs】 → 存成檔案留著，之後還能用

  按【複製】，按鈕會變成「已複製」。


【第 10 步】貼進 XQ 並編譯

  1. 打開 XQ 全球贏家
  2. 找到「XScript 編輯器」（在策略選單裡）
  3. 新增一支腳本，類型選對（選股 / 警示 / 指標 / 自動交易，
     軍師在說明裡會告訴你這支是哪一種）
  4. 在編輯區按 Ctrl + V 貼上
  5. 按鍵盤上的【F6】編譯

  看到「編譯成功」就完成了，接著照 XQ 的流程加進選股中心或雷達。


【第 11 步】編譯失敗怎麼辦（很常見，不用緊張）

  1. 把 XQ 顯示的錯誤訊息【整段】複製起來
  2. 回到 XS 工坊，貼進輸入框，加一句「編譯失敗，錯誤訊息如下」
  3. 按送出

  軍師會看懂錯在哪並修好，只改該改的地方，不會把你的腳本重寫。

  想調整內容也是一樣的做法，直接講就好：
    「停損改成 ATR 動態的」
    「再加一個條件：還要站上月線」


────────────────────────────────────────────────────────────
  下次要怎麼打開
────────────────────────────────────────────────────────────

  方法一（推薦）：先在 XS 工坊畫面左下角按一次【放到桌面】，
                  以後從桌面上的「XS 工坊」圖示打開就好。

  方法二：回到那個解壓縮出來的資料夾，一樣連點兩下【XS 工坊.exe】。

  ⚠ 不要把資料夾搬走或改名，程式會找不到自己的檔案。
     真的要搬，整個資料夾一起搬。

  ⚠ 用完想關掉：把那個黑底白字的視窗關掉就好。
     只關瀏覽器分頁的話，程式其實還在背景跑。


────────────────────────────────────────────────────────────
  遇到問題
────────────────────────────────────────────────────────────

  ▍點兩下沒反應，或視窗閃一下就不見了
     多半是還沒解壓縮，就在壓縮檔裡面點了。回到第 2 步重做。

  ▍Windows 說「已封鎖此檔案」
     在你下載的那個 .zip 上按右鍵 →【內容】→
     最下面如果有【解除封鎖】的核取方塊，勾起來 → 按【確定】，
     然後【重新解壓縮一次】。

  ▍畫面打不開，或瀏覽器顯示「無法連線」
     確認那個黑底白字的視窗還開著。它裡面會顯示一個網址
     （像 http://127.0.0.1:5101/），複製那個網址貼到瀏覽器也可以。

  ▍AI 沒有回應，或跳紅色錯誤
     左下角點【AI 連線】→【測試連線】，看它說什麼。
     訊息會直接告訴你缺什麼、該去哪裡處理。

  ▍軍師說「XS 知識庫中查不到」
     這是它誠實告訴你資料庫裡沒有這個東西，不是故障。
     換個講法再問一次，或把你在 XQ 裡看到的欄位名稱直接貼給它。

  ▍資料夾裡的檔案好像變少了
     程式第一次啟動時會把用不到的程式檔設成隱藏，讓你不會點錯。
     檔案都還在，沒有被刪掉。
